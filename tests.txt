ТЕСТЫ ПРИЛОЖЕНИЯ mathtool.py
Запуск: python mathtool.py solve   (коэффициенты вводятся с клавиатуры)
        python mathtool.py solve -a A -b B -c C

1. Коэффициенты (оба способа ввода дают одинаковый результат)
-------------------------------------------------------------------------------
№     A        B       C       Ожидаемый результат
----- -------- ------- ------- ------------------------------------------------
1     1        -3      2       Квадратное; D = 1; x1 = 2.000; x2 = 1.000; код 0

2     1        -2      1       Квадратное; D = 0; x = 1.000; код 0

3     1        0       5       Квадратное; D = -20; действительных корней нет; код 0

4     0        2       -4      Линейное; x = 2.000; код 0

5     0        0       0       Не уравнение: неизвестного нет; ошибка в stderr; код 1

6     0        0       7       Не уравнение: неизвестного нет; ошибка в stderr; код 1

7     abc      1       1       ОШИБКА: коэффициент не является целым числом; код 1

8     50000    1       1       ОШИБКА: значение вне допустимого диапазона; код 1

9     1        1       -50000  ОШИБКА: значение вне допустимого диапазона; код 1

10    1        2.5     1       ОШИБКА: коэффициент не является целым числом; код 1

11    10000    -10000  10000   Квадратное; D = -300000000; действительных корней нет; код 0
                               (граничное допустимое значение)

12    1        -3      1       Квадратное; D = 5; x1 = 2.618; x2 = 0.382; код 0

13    0        3       2       Линейное; x = -0.667; код 0
-------------------------------------------------------------------------------

2. Тесты, не сводящиеся к набору коэффициентов
-------------------------------------------------------------------------------
14. Команда: python mathtool.py
    Результат: выводится справка; код 0

15. Команда: python mathtool.py --help
    Результат: выводится справка; код 0

16. Команда: python mathtool.py foo
    Результат: в stderr "ОШИБКА: неизвестная команда 'foo'..."; код 1

17. Команда: python mathtool.py solve -a 1 -b 2
    Результат: в stderr "ОШИБКА: неверный набор параметров..." (пропущен параметр); код 1

18. Команда: python mathtool.py solve -a 1 -b 2 -c 3 -d 4
    Результат: в stderr "ОШИБКА: неверный набор параметров..." (лишний параметр); код 1

19. Команда: python mathtool.py solve -x 1 -b 2 -c 3
    Результат: в stderr "ОШИБКА: неизвестный параметр..."; код 1

20. Команда: python mathtool.py solve, ввод: 1, -3, 2
    Результат: Уравнение квадратное; D = 1; x1 = 2.000; x2 = 1.000; код 0

21. Команда: python mathtool.py solve, ввод: 1, xyz, 2
    Результат: в stderr "ОШИБКА: коэффициент не является целым числом"; код 1
